# ПРОМПТ 04. Глубокий разбор сфер жизни

Используй результаты слепого аудита и проверки биографией. Терминологию применяй внутри рассуждения, но не выноси читателю: он не астролог.

**Правило доступности варги.** Если нужная дробная карта не получена на этапе 01 — сфера разбирается только по домам D1 и **явно помечается**: «без карты D_ оценка ограничена». Не имитировать глубину, которой нет.

## Формат каждой сферы

**Суть** — что действительно важно понять.

**Как проявляется** — 2–4 примера, максимально близких реальной биографии. Неподтверждённый пример вводится словами «Например, это может проявляться так…».

**Зрелое проявление** / **Незрелое проявление** / **Главная ловушка**

**Что делать** — 3–5 конкретных рекомендаций.

**Оценки:** Важность для текущей жизни: N/100 · Важность для дальнейшего пути: N/100 · Уверенность: высокая/средняя/гипотеза

**Объём раздела определяется важностью для этого человека, а не шаблоном.** Сферы, названные клиентом приоритетными, расширяются; заведомо второстепенные — сокращаются до нескольких строк.

## Список сфер

1. **Брак, любовь, партнёрство** (VII + D9) — тип отношений, кого притягивает, близость/свобода, конфликты, повторяющиеся сценарии, устойчивость союза.
2. **Карьера, профессия, статус** (X + D10) — предприниматель/сотрудник, лидер/эксперт, масштаб, среда, следующий этап. ТОП-5 направлений с баллами и обоснованием.
3. **Деньги, богатство, капитал** (II + XI + D2) — заработать → сохранить → приумножить → использовать; бизнес, инвестиции, риск, дисциплина, типичные ошибки.
4. **Дети, творчество, интеллект** (V + D7) — количество не угадывать; стиль родительства, тип интеллекта, творчество.
5. **Личность и жизненная сила** (I) — характер, решения, лидерство, эмоциональность. Каждое сильное качество — с обеих сторон.
6. **Здоровье и устойчивость** (I + VI + VIII + D6) — без диагнозов: тенденция → пример → профилактика → образ жизни. Приоритет медицины указывается явно.
7. **Зрелость души и внутренний путь** — что развито, что развивается, привязанности, реакции. Без подсчёта воплощений.
8. **Дом, мать, опора, недвижимость** (IV + D4) — внутренняя опора отдельно от материальной собственности.
9. **Дхарма, удача, отец, учителя** (IX) — когда жизнь начинает помогать; риск идеализации наставников.
10. **Кризисы, трансформация, ресурсы** (VIII + D8) — без предсказания даты смерти.
11. **Кармические долги и сценарии** — паттерн → пример → триггер → реакция → последствия → зрелая форма → отработка. Без языка наказания и вины.
12. **Работа, служение, конкуренция** (VI) — рутина, сотрудники, конкуренты, долги.
13. **Духовный путь и практики** (IX + XII + D20) — ТОП-5 практик с баллами: почему подходит, что развивает, возможная ошибка, как встроить в жизнь.
14. **Глубинная карма** (D60) — **только при подтверждённом времени рождения**. Без придуманных историй прошлых жизней. Если время не подтверждено — раздел пропускается с явной пометкой.
15. **Потери, расходы, уединение** (XII) — различать потерю и сознательное отпускание.
16. **Родители и родовые сценарии** (IV + IX + D12) — что сохранить / изменить / не передавать дальше.
17. **Братья, сёстры, смелость** (III + D3) — коротко, если тема несущественная.
18. **Комфорт, транспорт, удовольствия** (D16).
19. **Образование и усвоение знаний** (D24) — если карта получена.
20. **Трудные паттерны** (D30) — если карта получена; для поиска точек гармонизации, не для запугивания.

**Упаи в этом промпте не пишутся.** Они вынесены в отдельный Промпт 08 — именно потому, что в версии 1.0 раздел упай систематически оставался недописанным «хвостом» этого этапа.

## Контроль объёма

Этап большой. Если ответ рискует обрыв по длине — разбить на две части по сферам (1–10, 11–20) и выдать последовательно, не сокращая содержание.

## Сводка этапа

По каждой сфере — одна строка сути + оценки. Отдельно: список сфер, оценка которых ограничена отсутствием варг.
